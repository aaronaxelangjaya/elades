# 📚 Aplikasi Perpustakaan CLI

Program aplikasi perpustakaan berbasis Command Line Interface (CLI) menggunakan Python. Program ini menerapkan konsep Pemrograman Berorientasi Objek (OOP) dan penyimpanan data menggunakan file CSV.

## ✨ Fitur
- Menambahkan data buku.
- Menampilkan daftar buku.
- Menyimpan data buku ke `buku.csv`.
- Menggunakan class `Buku` dan `Anggota`.
- Memisahkan program ke beberapa file Python agar lebih terstruktur.

## 📁 Struktur File

```text
aplikasi_perpustakaan/
├── main.py
├── models.py
├── tambah_buku.py
├── tampil_buku.py
└── buku.csv
```

## 🛠️ Teknologi
- Python 3
- CSV
- Object-Oriented Programming (OOP)

## 🚀 Cara Menjalankan

1. Pastikan Python 3 sudah terpasang.
2. Clone repository ini:

   ```bash
   git clone URL_REPOSITORY
   ```

3. Masuk ke folder proyek.
4. Jalankan program:

   ```bash
   python main.py
   ```

## 📖 Cara Menggunakan
1. Pilih menu Tambah Buku untuk memasukkan data buku.
2. Masukkan judul, penulis, dan ISBN.
3. Pilih menu Tampilkan Buku untuk melihat daftar buku.
4. Data buku akan disimpan dalam file `buku.csv`.
5. Pilih Keluar untuk mengakhiri program.

## 🎯 Tujuan Pembelajaran
- Memahami struktur program Python.
- Memahami penggunaan class, atribut, constructor, dan method.
- Memahami penggunaan file CSV untuk penyimpanan data.
- Memahami cara memodifikasi kode untuk studi kasus yang berbeda.

## 👨‍💻 Penutup

Proyek ini dibuat sebagai latihan pembelajaran Python, khususnya penerapan OOP, pengelolaan file CSV, dan pembuatan aplikasi berbasis CLI.
